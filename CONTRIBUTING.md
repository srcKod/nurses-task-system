# Contributing

This is a learning project, not a maintained library. Issues and pull
requests are welcome — as discussion, not as support requests.

If you spot a bug, an inconsistency, or a clearer way to explain something
in `LEARNING.md` or `KNOWN-ISSUES.md`, open an issue or PR. There's no
required template; a short description and a screenshot (if relevant) is
enough.

There is no formal code style requirement. The project is what it is. If
you're proposing a substantive change to the application code (not the
docs), please open an issue first to discuss — many of the issues in
`KNOWN-ISSUES.md` are intentional, and the "fix" might not be the fix.
